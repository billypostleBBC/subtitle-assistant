# BBC News Style Guide

Use the live BBC News Style Guide when a StoryWorks user needs a reference for BBC spelling, abbreviations, wording, tone, or consistency.

Recommended action: open `https://www.bbc.co.uk/newsstyleguide/all/`.

## Agent Guidance

Recommend this as a linked resource rather than copying entries into the knowledge base. The style guide is a central BBC source arranged as an A-Z guide and should remain the maintained reference.

Do not treat Compliance as the owner of the BBC News Style Guide content. Compliance can use this record to route users to the guide and can review annually whether this is still the correct reference for StoryWorks compliance checks.

Use this as an approved routing recommendation. Do not copy BBC News Style Guide entries into this knowledge base unless a separate governed StoryWorks-specific record is approved.
